# Охиддоо сургах 50 зүйл

![Охиддоо сургах 50 зүйл](images/cover/78180998510492671.png)

Жина Мейджорс, охиныхоо 18 нас хүрсэн өдөрт зориулан, 50 зүйлээс бүрдсэн энэхүү жагсаалтыг бичжээ. Энэ жагсаалт нь, олон жилийн амьдралын туршлага дээр суурилсан, охидууд энэ бүхнийг амьдралын явцад мэдэж авах хугацааг хэмнэх, зөв амьдрахад тустай, хэдийгээр, нэг ээж илэрхийлсэн боловч, нийт ээжүүдийн охиддоо өгөх сургаал юм.

![](images/21258550902.jpg)

Юуны түрүүнд өөрийгөө хайрла. \
Сургуульд суралцах үе чинь, бодит амьдрал биш, жинхэнэ амьдралыг угтахад бэлд.\
Амьдралд чамтай олон муу охид таарна. Түвшингээ мэдэж, дэргэдүүр нь өнгөр. \
Хэрэв чи, жинхэнэ найзаа олсон бол, хол ойр, тусдаа байгаагаас шалтгаалахгүй нөхөрлөлөө хадгалахыг хичээ. Эд зүйлс чамайг аз жаргалтай болгохгүй гэдгийг үргэлж санаж яв. \
Чи, өөрөө хэнийг ч бүү шүүмжил, харин, чи өөрөө шүүмжлэлд бэлэн бай, учир нь урд чинь шүүмжлэл дүүрэн амьдрал байгаа. Харцаа дээгүүр яв, охин минь. \
Эмээгээ жинхэнээсээ танихыг хичээ. Их зүйл өгнө. \
Ямар ч, хүнд бэрх асуудал, хорвоогийн төгсгөл биш шүү. \
Өөрийгөө бусадтай бүү харьцуул. Тэд хэзээ ч, чам шиг болж чадахгүйтэй адил, чи мөн тэдэнтэй адил болж чадахгүй. Өөрөөрөө бай. Чи, давтагдашгүй гэдгээрээ бахарх. \
Чи хүнд хичнээн хайртай байсан, толгойгоо бүү гээгээрэй. \
Ярь, ярилцаж бай. Ингэж байж өөрийн дуу хоолойг олох бөгөөд түүнийгээ ашиглаж чаддаг болдог. \
“Үгүй” гэдэг үгийг хэлж, хэрэглэж, ашиглаж сур. \
Өөрийнхөө амьдралын түүхийг бичих хэрэг гарвал, үг өгүүлбэр бүрээ аз жаргалтай агшингуудын дурсамжаар дүүргэж бичээрэй. \
Хэзээ ч, эр хүний хойноос бүү хөөцөлд. Эр хүн чамайг олох нь зөв. \
Магтаалыг зөвөөр ойлгож, түүнд итгэхийг оролдож бай. \
Мөнхөд шударга бай. \
Өөрөөрөө жаргалтай байж сур, ганцаардлаас бүү айж бай. \
Мэдэрч буй зүйлээ хуваалцахаас битгий айгаарай. \
Маргалдаж болно, хэрүүлээс хол бай. \
Гарт тааралдсан болгоноо уншиж бай. Мэдлэг бол юунаас ч хүчтэй зэвсэг юм. \
Чи, хэн нэгэн залуугийнд уригдаад, түүний гэрт нь, нэг ч ном байхгүй байвал холхон явсан нь дээр. \
Чи, хэний ч хувийн өмч биш. \
Өөрийгөө хамгаалах чадвартай бай. Үргэлж. \
Азгүйтэлд өртөхөөс бүү ай. Азгүйтэл, уналтаас, асар олон зүйлд суралцдаг. \
Хэзээ ч, хэнд ч, сонингийн нүүр дээр хэвлүүлж болохгүйд тооцох зүйлээ электрон шуудангаар бүү явуул. Чи, түүнийгээ устгасан ч, хэзээд илрэх магадлал дагуулна. \
Хүмүүст, тусалж бай. Сайн үйлс аз жаргалыг авчирна. \
Сайхан сэтгэлийг эрхэмлэ. Талархал зан чанарыг нээж байдаг. \
Зөн совингоо сонсож бай. Итгэ. \
Эелдэг бай. \
Чиний үйл хөдлөл, чиний хэлж ярьсанаас чинь илүү чамайг илэрхийлнэ. \
Мэдрэмж, сэтгэлээ битгий нууж бай, илэрхийлэх арга олох хэрэгтэй. \
Бүх зүйлсээс сайн, сайхныг нь олж харж сур. \
Нарнаас хамгаалах тос үргэлж хэрэглэж бай. \
Өөртөө хайртай хүмүүстэй үргэлж харьцаатай бай. \
Амьдралын туршид, харц дээгүүр яв. Итгэлтэй байдал дур булаам байдаг. \
Уйлмаар бол уйл, нулимснаасаа шинэ хүчийг олж авч бай. \
Инээд нь, сэтгэл санааны эм юм. \
Хөгжим хэт чанга байна гэж үү? Бүжиглээч. \
Үг, яриа гүүрийг босгож эсвэл шатааж чадна. Бодолтой ярьж бай. \
Гэр орон бол чамайг хайрладаг газар. Харин амьдардаг хаяг биш. \
Түрүүлж уучлалт гуйх нь сул доройн шинж биш. \
Ажилла, ажиллаад бай. Үргэлжид өөрийнхөө хэрэгцээг хангах чадвартай бай. \
Чи, заримдаа надад дургүйлхдэгийг чинь би, мэднэ. Харин, би чамд үргэлжийн мөнх хайртай байдаг. \
Чи бол, бүхий л зүйл чинь бүрэн бүтэн, өөрийгөө хангах чадвартай хүн. \
Чи, өөрийгөө бодож байгаагаас авъяаслаг. Өөрийгөө бусадтай битгий харьцуул.\
Өчигдөрөөр, маргаашаар бүү амьдар. Үүнийг хэн ч хянах боломжгүй. Өнөөдөртөө аз жаргалтай бай.
