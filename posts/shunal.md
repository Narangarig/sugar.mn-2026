# Шунал

![Шунал](images/cover/28012812025441067.jpg)

![](images/5241621903.jpg)

Нэгэн ажилгүй инженер, ажилд орох гээд удаан хугацаанд чадаагүй тул хувийн эмнэлэг нээхээр шийджээ. Эмнэлгийн байшин дээрээ, “өвчнийг эмчлэх-5000, хэрэв эмчилж чадахгүй бол 10000-г буцааж олгоно” гэсэн сурталчилгааны самбар байрлуулав. Дэргэдүүр нь өнгөрч явсан нэг эмч, үүнийг ашиглан мөнгөжихөөр шийдэн, эмнэлэг рүү оров. Тэрээр мэндлээд, \
-Би амт мэдрэхээ больчихлоо, эмчлээд өгөөч, гэсэн хүсэлт тавив. Эмнэлгийн эзэн инженер: \
-Сувилагч аа! 22 дугаарын савлагаатай бодисыг авч ирж, өвчтөнд өгнө үү. Сувилагч: \
-Та, амаа ангайна уу... \
-Хөөе! Энэ чинь бензин байна шүү дээ, та нар яаж байгаа юм? \
-Танд, баяр хүргэе! Та амт мэдэрдэг боллоо. Эмчилсний хөлс 5000. \
Эмч, уур нь хүрсэн ч мөнгийг төлөхөөс өөр аргагүй тул өгөөд явав. Гэсэн ч тэр, мөнгөө буцааж авах санаатай, дахин ирэв. Тэр: \
-Ой санамжаа гээчихлээ. Туслаач. Гэсэн хүсэлт тавив. \
-Сувилагч аа! 22 дугаартай, сиропыг өвчтөнд өгнө үү. \
-Та амаа ангайна уу... \
-Энэ чинь нөгөө бензин л байна шүү дээ, гэж уурсахад, \
-Танд, баяр хүргэе! Таны ой санамж сэргэлээ, эмчилсний хөлс 5000, гэхэд уурсаж хилэгнэсэн эмч мөнгөө төлөөд, яаж мөнгө хожихоо бодсоор гарчээ. Удалгүй дахин ирсэн бөгөөд, тэр: \
-Би хараагүй болчихлоо, эмчлээд өгөөч, гэжээ. Эмнэлгийн эзэн: \
-Уучлаарай тун харамсалтай байна. бид үүнийг эмчилж чадахгүй. Мөнгөө авна уу. Энэ таны 10000. \
-Үгүй энэ чинь, 5000 л байна шүү дээ. \
-Танд баяр хүргэе! Таны хараа сэргэлээ. Эмчилсний хөлс 5000. \
Ха, ха ха
