# Аз завшаан танд дуртай юу?

![Аз завшаан танд дуртай юу?](images/cover/19533384209534103.jpg)

Энэ асуултад хариулах нэгдсэн нэг хариулт байхгүй ч, эртний мэргэд, аз завшаан, азгүйтлийн аль нэгийг татах байршил, орон зай байдаг гэж үздэг байжээ. Амьдран буй орчин, амьдралыг хүлээн авах чадвар үүнд нөлөөлдөг бөгөөд гадаад орчин нөхцөл нь хүний дотоод ертөнцтэй зохилдлогоонд байгаа цагт аз завшаан үргэлж дагадаг, үүнийг тайлбарлах, мөрдөхөд зориулагдсан бүхэл бүтэн салбар ухаан гэхүйц фэн-шуйн ухаан байдаг байна. Үүн дээр үндэслэсэн дараах тестээр өөрийгөө шалган аз завшаан тань ойр байгаа эсэхийг мэдэж аваарай.

![](images/4493246553.jpg)

Асуултуудад тайвнаар нухацтай хариулан, хариултын оноог нэгтгэн харгалзах тайлбарыг уншаарай.\
**Ширээний өнцөгт ганцхан сул сандал байна.** \
а/ Шууд сууна 0 оноо\
б/ Суухгүй зогсно 2 оноо\
**Зочидыг үдэхдээ**\
а/ Гэрээсээ гаралгүй буюу босгоо давалгүй баяртай гэж хэлээд үднэ 0 оноо\
б/ Гэрээсээ гарч зочидоо үддэг 2 оноо\
**Сайхан хоол бэлтгэхэд аль нь илүү чухал вэ?** \
а/ Сэтгэл гарган бэлтгэх 0 оноо\
б/ Сэтгэл гаргаагүй ч сайн хүнсээр амттай болно 2 оноо\
**Ард чинь хэн нэгэн зогсоод байхад эвгүйцдэг үү?** \
а/ Тийм 0 оноо\
б/ Үгүй 2 оноо\
**Орон гэрийн чинь булан гэсэн ойлголт**\
а/ Ажиллах, амрах булан 0 оноо\
б/ Хоосон орон зай 2 оноо\
**Өдрийн цагаар цонх тань**\
а/ Хөшиг татаастай байдаг 0 оноо\
б/ Гэрэл гэгээ оруулахын тулд үргэлж нээлттэй байдаг 2 оноо\
**Хүнтэй харилцах үедээ гарын хөдөлгөөн тань**\
а/ Өөрийгөө заадаг 0 оноо\
б/ Хэн нэгнийг заадаг 2 оноо\
**Та гэртээ гар утсаа орхичихсон**\
а/ Буцаж гартээ орно 0 оноо\
б/ Гар утасгүй явна 2 оноо\
**Таны унтдаг ор**\
а/ Шал ор хоёрын хооронд зай байдаг 0 оноо\
б/ Шалнаас зайгүй 2 оноо\
**0-6 оноо.** Та фэн-шуйг хэрэгсдэггүй. Аз завшаан тэр бүр тохиолдох нь ховор. Хэдийгээр яльгүй мэт санагдавч, зарим зүйлсийг мөрдөх, хэрэгжүүлэх гээд оролдоод үзээрэй. Удаан хүлээлгэхгүй аз завшаан тан руу хандах болно.\
**8-12 оноо.** Баяр хүргэе аз завшаан таны талд байна. Санамсаргүй тохиолдолд ч таныг аз ивээж байдаг. Гэхдээ үргэлж биш. Орон гэр, байгаа орчиноо анзаараарай. Ажилын ширээн дээрээ, эсвэл ойролцоо сайхан таримал цэцэг тавиарай. Гэрийнхээ засвар, чимэглэлд анхаар. Амьдрал чинь хэрхэн эерэгээр өөрчилөгдөхийг тон удалгүй анзаарна.\
**14-с дээш оноо.** Та, атаархам азтай хүн юм. Зөн совин тань гайхалтай хөгжсөн. Аз завшаан үргэлж таны талд байхаас гадна, таны амьдралын бүхий л тохиолдлуудыг дагалдаж байдаг. та, эргэн тойронтойгоо, орчлон ертөнцтэй гайхалтай нийцэл зохилдлогоонд оршдог. Гэр орны чинь хана хүртэл таныг эерэг эрч хүчээр тэтгэж байдаг байх нь. Бүх зүйл гарт тань байна.
